## 一分钟看懂目录

```
src/
├── api/        数据访问层（页面唯一出口）
│   ├── client.js     云客户端 + ApiError + unwrap
│   ├── auth.js       登录 / 微信 / 短信验证码
│   ├── profile.js    用户资料
│   ├── community.js  动态 / 评论 / 点赞
│   ├── relation.js   关注 / 粉丝
│   ├── catalog.js    商品 / 农场 / 分类
│   └── index.js      统一导出
├── mock/       演示数据，字段与真实表一致
├── common/     enums.js 枚举字典、utils.js 工具、avatar.js 兜底头像
├── components/ UI 组件
├── pages/      页面
└── store/      本地状态（购物车/订单/地址/收藏）
```

## 三条不能破的规则

1. 页面不出现 `snake_case`，不出现 `from('表名')`。
2. 一个概念只用一个名字（`owner_id` / `author_name` / `userId` 各司其职）。
3. 改字段 = 改表 + 改 VM + 改文档，三件一起做。
