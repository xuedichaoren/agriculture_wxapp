## 一分钟看懂目录

```
src/
├── api/        数据访问层（页面唯一出口）
│   ├── client.js     云客户端 + ApiError + unwrap
│   ├── auth.js       登录 / 微信 code 换 token（短信两函数保留但页面未用）
│   ├── profile.js    用户资料
│   ├── community.js  动态 / 评论 / 点赞
│   ├── relation.js   关注 / 粉丝
│   ├── catalog.js    商品 / 农场 / 分类
│   ├── adopt.js      地块 / 作物 / 套餐 / 价格 / 进度
│   ├── adopt-plan.js 认养详情视图 / 配送计划 / 农事时间轴
│   ├── adopt-live.js 云监工（机位 / 环境读数 / 抓拍 / 远程派单）
│   ├── adopt-harvest.js 收成（预估 / 已收 / 去向 / 记录）
│   ├── adopt-cert.js 认养证书（编号 / 验真码）
│   └── index.js      统一导出
├── mock/       演示数据，字段与真实表一致
├── common/     enums.js 枚举、utils.js 工具、avatar.js 兜底头像
│              theme.js 设计令牌、assets.js 插图槽、roles.js 身份定义
│              disease-kb.js 病害知识库、image-feature.js 端侧图像特征
├── components/ UI 组件（含 ui-* 11 个基础组件）
├── pages/      页面（54 个）
└── store/      本地状态（购物车/订单/地址/收藏/身份/问诊/诊断/售卖）
```

## 三条不能破的规则

1. 页面不出现 `snake_case`，不出现 `from('表名')`。
2. 一个概念只用一个名字（`owner_id` / `author_name` / `userId` 各司其职）。
3. 改字段 = 改表 + 改 VM + 改文档，三件一起做。
