# 08 · UI 组件库与插图指南

这份文档给两类人看：
- **改页面的人**：从这里取颜色、圆角、间距，用现成组件，不要再写死色值。
- **出图的人**：按第 4 节的槽位清单出图，丢进对应目录就能自动替换，不用改代码。

预览入口：小程序里访问 `/pages/dev/ui`（个人中心 → 工具里也有入口），能看到所有组件的实际效果 + 全部插图槽。

---

## 一、三条规矩

1. **颜色只有一个出处**：`common/theme.js` 的 `C`。页面里出现 `#0FC97A` 这种十六进制就是错的。
2. **尺寸只写 rpx**：需要用变量拼接时用 `n(24)` → `'24rpx'`。
3. **能用组件就不写结构**：卡片、按钮、标签、列表项、分段、弹层都有现成的，手写一遍等于以后改两次。

### 2.2 语义色 `TONES` / `tone()`

每个色调给「主色 / 浅底 / 描边」三件套，标签、徽章、状态点都用它：

```js
tone('warn')  // { color: '#FF8A3D', soft: '#FFF4E4', line: '#FFE2BC' }
```

可用名：`brand` / `danger` / `warn` / `info` / `purple` / `gold` / `gray`。

### 2.3 渐变 `G`

| 令牌 | 说明 |
|---|---|
| `G.brand` | 135° 主绿渐变，按钮与强调块 |
| `G.brandSoft` | 浅绿对角渐变，卡片底 |
| `G.header` | 160° 深绿三段，页面顶部大色块 |
| `G.sunset` | 橙黄，促销、时令 |
| `G.sky` | 蓝，天气、水肥 |
| `G.soil` | 土黄，地块、认养 |
| `G.mask` | 透明到深色，图片上压文字时用 |

### 2.4 圆角 / 阴影 / 字号 / 间距

```js
R  = { xs:'8rpx', sm:'14rpx', md:'20rpx', lg:'28rpx', xl:'36rpx', pill:'999rpx' }
SH = { card:'0 8rpx 30rpx rgba(22,60,45,.05)',
       float:'0 16rpx 44rpx rgba(6,120,80,.18)' }
FS = { h1:'40rpx', h2:'34rpx', h3:'29rpx', body:'26rpx', sub:'24rpx', mini:'21rpx', tiny:'19rpx' }
SP = [4,8,12,16,20,24,28,32,40,48,56]     // 间距刻度，只从这里取值
```

阴影**只有两档**：卡片 `SH.card`、浮层 `SH.float`。不要自己编第三档。

### 2.5 样式片段 `S`

拼内联样式时用，减少重复字符串：

```js
S.row           // display:flex;align-items:center
S.rowBetween    // ...justify-content:space-between
S.col / S.flex1 / S.ellipsis
```

## 三、组件库（11 个）

> **重要**：组件放在**扁平目录** `components/ui-xxx.vue`（不是 `components/ui-xxx/ui-xxx.vue`），所以必须在 `pages.json` 的 `easycom.custom` 里注册正则，否则页面里写了 `<ui-card>` 也不会编译进去，而且**构建不报错**，只在真机上白屏。
>
> ```json
> "easycom": {
>   "autoscan": true,
>   "custom": {
>     "^ui-(.*)$": "@/components/ui-$1.vue"
>   }
> }
> ```
>
> 新增 `ui-*` 组件不用再改这里，正则自动覆盖。

### 3.1 `ui-card` 卡片

内容容器，最常用。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `title` | String | `''` | 标题 |
| `sub` | String | `''` | 副标题（跟在标题右边） |

| `marginBottom` | Number/String | `20` | 下外边距 |

### 3.7 `ui-image` 插图槽 ⭐

**这个组件是「先占位、后补图」的核心**：页面里只写槽位 key，图片没准备好时显示带提示的占位块，图片丢进 `static/images/` 后自动替换，页面代码一行不用改。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| **`name`** | String | `''` | **插图槽 key**，见第 4 节 |
| `src` | String | `''` | 直接给地址，优先级高于 `name` |
| `h` | Number/String | `''` | 固定高度（rpx）；不给则按 `ratio` 自适应 |
| `ratio` | Number | `0` | 宽高比 |
| `radius` | String | `20rpx` | 圆角 |
| `round` | Boolean | `false` | 圆形 |
| `mode` | String | `aspectFill` | 图片裁剪模式 |
| `lazy` | Boolean | `false` | 懒加载 |
| `tip` | Boolean | `false` | 占位时显示「建议尺寸/内容」，开发期开，上线关 |
| `mark` | Boolean | `false` | 占位时右上角标「待插图」，仅 dev 页用 |

> ⚠️ 属性名必须是 **`name`**，不能叫 `slot`——会和 Vue 的插槽属性打架，编译期直接失效且不报错。

```html
<!-- 按槽位（推荐） -->
<ui-image name="home.banner.farm" :h="400" radius="28rpx" />

<!-- 按槽位并显示开发提示 -->
<ui-image name="scan.guide" tip />

<!-- 直接给地址 -->
<ui-image src="/static/images/farm/hero.png" :h="360" />
```

## 四、插图槽清单（16 处）

### 4.1 图片放哪、怎么命名

```
static/images/
├── home/       banner-farm.png  banner-season.png  entry-scan.png  entry-expert.png
├── farm/       hero.png  plot.png  workbench.png
├── expert/     hero.png  avatar-default.png
├── scan/       guide.png  empty.png
├── role/       buyer.png  farmer.png  expert.png
├── profile/    header.png
└── community/  banner.png
```

规则：
- 路径 = `static/images/` + 槽位里的 `file` 字段，**大小写敏感**。
- 格式优先 **WebP**，不支持时用 **PNG**；照片类可用 JPG（质量 80）。
- 单张控制在 **200KB 以内**，小程序主包 2MB 是硬上限。
- 命名全小写、连字符分隔，不要中文、不要空格。
- 2 倍图按表里的 `w×h` 出，3 倍图可出 1.5 倍尺寸，代码不用改。

### 4.3 出图风格统一要求

- **色调**：以品牌绿 `#0FC97A` 为主，辅以土黄、暖橙；不要出现冷调蓝紫（专家身份的 `C.purple` 除外）。
- **人物**：真实感优先，不要卡通风；农户形象要在地（草帽、胶鞋、田埂），不要摆拍棚拍。
- **背景**：浅色、干净、留白多，因为上方要压文字或按钮。
- **避免**：大段文字、水印、logo、明显的第三方品牌。
- **一致性**：同一模块的几张图（如三张身份卡）用同一套光源和色温。

### 4.4 把一个「待挂载」的槽位接到页面上

三种典型场景，照着套就行。

**① 作为普通内容块（最简单）**

```html
<ui-image name="scan.guide" :h="352" radius="26rpx" />
```

**② 作为头部背景层（`profile.header`、`community.banner`、`farm.hero` 这类）**

父容器加 `position: relative; overflow: hidden`，图片绝对定位铺满、置底，内容用 `z-index: 1` 压在上面：

```html
<view class="head">
  <view class="head-bg">
    <ui-image name="profile.header" h="100%" radius="0" mode="aspectFill" />
  </view>
  <view class="head-main">
    <text class="head-name">{{ user.nickname }}</text>
  </view>
</view>
```

```css
.head { position: relative; overflow: hidden; height: 400rpx; }
.head-bg { position: absolute; left: 0; top: 0; right: 0; bottom: 0; z-index: 0; }
.head-main { position: relative; z-index: 1; padding: 40rpx 28rpx; }
```

背景层建议在图片上加一层半透明遮罩，保证白字可读：

```css
.head-bg::after {
  content: '';
  position: absolute; left: 0; top: 0; right: 0; bottom: 0;
  background: linear-gradient(180deg, rgba(10,40,28,0) 0%, rgba(10,40,28,.45) 100%);
}
```

（也可以直接用令牌 `G.mask`。）

**③ 作为列表项图标（`home.entry.scan` 这类）**

原来是渐变底 + Emoji 的圆形图标，换成图片时保留外圈容器、只换内层：

```html
<view class="q-icon">
  <ui-image name="home.entry.scan" :h="96" round />
</view>
```

> 接之前先把图放进 `static/images/`。图没到位时 `ui-image` 显示的是槽位自带的渐变底 + Emoji 占位，
> 视觉上不会塌，但也不代表「已经接好了」——以 `pages/dev/ui` 里能不能看到真图为准。

### 4.5 新增一个插图槽

1. 在 `common/assets.js` 的 `IMAGES` 里加一条：

   ```js
   'promo.coupon': {
     file: 'promo/coupon.png',
     w: 600, h: 300, ratio: 2,
     tip: '优惠券横幅：绿底 + 券面留白',
     emoji: '🎟️',
     bg: ['#EAF9F1', '#CFF3E0']
   }
   ```

2. 页面里直接写 `<ui-image name="promo.coupon" />`。
3. 图还没出的时候，`pages/dev/ui` 会自动把它列进清单，点一下能复制路径发给设计。

**不需要改任何组件或构建配置。**
