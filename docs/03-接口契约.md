# 接口契约

> 所有页面只能通过 `import * as api from '@/api/index.js'` 调用。
> 契约 = 函数名 + 入参（camelCase 对象）+ 返回 VM（camelCase）+ 失败抛 `ApiError`。
> **后端按此实现 REST/SDK 均可，前端不用改页面。**

---

## 1. 通用约定

| 项 | 约定 |
|---|---|
| 入参 | 单个对象 `{ ... }`；只有 id 时可直接传字符串 |
| 返回 | 成功返回 VM / 数组 / null，**不返回 `{ data, error }`** |
| 失败 | `throw ApiError`，带 `code` + 中文 `message` |
| 登录态 | 未登录时抛 `code === 'unauthenticated'`，页面据此弹登录 |
| 分页 | `{ page = 0, size = 10 }`，返回数组；不足 `size` 条即视为到底 |
| 时间 | 返回 ISO 字符串（`timestamptz` 原值），页面自行格式化 |
| 空值 | 字符串统一 `''`，对象统一 `null`，数组统一 `[]`，**不返回 undefined** |

### 错误码

| code | 含义 | 前端处理 |
|---|---|---|
| `23505` | 唯一键冲突 | 视为幂等成功（已点赞 / 已关注） |
| `23503` | 外键不存在 | 提示「关联数据不存在」 |
| `42501` | 权限不足 | 提示重新登录 |
| `unauthenticated` | 未登录 | 弹登录框、跳登录页 |
| 其它 | 网络 / 未知 | 显示 `message` |

```js
import * as api from '@/api/index.js'

try {
  await api.createPost({ content: '今天第一批辣椒摘完了' })
} catch (e) {
  if (e.code === 'unauthenticated') return uni.navigateTo({ url: '/pages/login/login' })
  uni.showToast({ title: e.message, icon: 'none' })
}
```

## 2. 数据结构（VM）

### MeVM

```ts
{ userId: string, nickname: string, avatar: string }
```

### UserVM

```ts
{ userId, nickname, avatar, city, userRole, bio }
```

### PostVM

```ts
{
  id: number | string,
  authorId: string,          // 发布者 userId
  authorName: string,        // 发布时昵称快照
  authorAvatar: string,      // 头像（URL 或 emoji）
  authorRole: string,        // 农场主 / 农友 / 老主顾
  content: string,
  productId: string | '',    // 关联商品，可空
  images: string[],          // 图片 URL 或 emoji 占位
  topic: string,
  createdAt: string,
  updatedAt: string,
  likeCount: number,
  commentCount: number,
  isLiked: boolean,          // 我是否点过赞
  isMine: boolean            // 是否我发的（决定能否删除）
}
```

### CommentVM

```ts
{ id, postId, authorId, authorName, authorAvatar, content, createdAt, isMine }
```

### FollowStats

```ts
{ followingCount: number, followerCount: number }
```

### ProductVM（商品目录）

```ts
{
  id, name, spec, price, originalPrice, unit,
  categoryId, farmId, coverUrl, emoji, bg,
  salesCount, stockCount, tags: string[], summary, detailText
}
```

## 3. 登录鉴权 `src/api/auth.js`

| 函数 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `fetchSession()` | — | `session \| null` | 未登录不抛错，返回 null |
| `fetchMe()` | — | `MeVM \| null` | 未登录返回 null |
| `signOut()` | — | `void` | 清除会话 |
| `signInWithWechat(redirectTo)` | `string` | `url` | 返回需要 `location.assign` 的授权地址，仅 H5 |
| `sendSmsCode(phone)` | `string` | `{ verificationId, isExistingUser }` | 60 秒倒计时由页面维护 |
| `verifySmsCode({ phone, verificationId, isExistingUser, code })` | 对象 | `session` | 建立登录态 |
| `handleWechatCallback()` | — | `session \| null` | 仅 `App.vue onLaunch` 调用，code 一次性 |

## 4. 用户资料 `src/api/profile.js`

| 函数 | 入参 | 返回 |
|---|---|---|
| `fetchProfile(userId)` | `string` | `UserVM \| null` |
| `ensureProfile()` | — | `UserVM`（无资料则自动建档，并发安全） |
| `updateProfile(patch)` | `{ nickname?, avatar?, city?, userRole?, bio? }` | `UserVM` |

> `updateProfile` 只接受白名单字段，传 `owner_id` 会被忽略。

## 5. 农友圈 `src/api/community.js`

| 函数 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `fetchFeed({ page, size })` | 分页 | `PostVM[]` | 全站最新 |
| `fetchFollowFeed({ page, size })` | 分页 | `PostVM[]` | 仅已关注的人；未关注返回 `[]` |
| `fetchPostsByUser(userId, { size })` | id | `PostVM[]` | 个人主页动态 |
| `fetchPost(postId)` | id | `PostVM \| null` | null 表示不存在/已删除 |
| `createPost({ content, productId?, images?, topic? })` | 对象 | `PostVM` | content 为空抛错 |
| `deletePost(postId)` | id | `void` | 非本人抛错 |
| `fetchComments(postId)` | id | `CommentVM[]` | 时间正序 |
| `createComment(postId, content)` | id + 文本 | `CommentVM` | 空文本抛错 |
| `toggleLike(postId, isLiked)` | id + 当前状态 | `boolean` 操作后状态 | 幂等 |

发布示例：

```js
const post = await api.createPost({
  content: content.value,
  productId: linkedProduct.value?.id || '',
  images: photos.value.map((p) => p.emoji),
  topic: topic.value
})
```

## 6. 关注关系 `src/api/relation.js`

| 函数 | 入参 | 返回 |
|---|---|---|
| `fetchFollowing()` | — | `UserVM[]` |
| `fetchFollowers()` | — | `UserVM[]` |
| `fetchFollowStats(userId)` | `string` | `FollowStats` |
| `isFollowing(targetUserId)` | `string` | `boolean` |
| `follow(targetUserId)` | `string` 或 `UserVM` | `true`（幂等） |
| `unfollow(targetUserId)` | `string` | `false` |

> 禁止关注自己：`follow` 会抛错「不能关注自己」。
> 关系表不存昵称头像，返回的 `UserVM` 由 `user_profiles` join 得到。

## 8. 本地状态（非后端）`src/store/index.js`

购物车、订单、地址、收藏、足迹目前存在本地（`uni.setStorageSync`），字段已按同一套规范命名：

```js
cartItem   { productId, qty, isChecked }
order      { id, status, createdAt, items:[{ productId, qty }], addressId,
             freight, discount, remark, payAt,
             express: { company, trackingNo, nodeIndex }, isReviewed }
address    { id, name, phone, region, detailAddress, tag, isDefault }
```

`status` 取值见 `src/common/enums.js` 的 `ORDER_STATUS`；页面文案统一走 `orderStatusText()`。

## 9. 契约变更流程

1. 后端改表 → 在 `docs/02-数据字典.md` 更新列说明；
2. 前端改 `src/api/*.js` 的 `toXxxVM()` → 更新本文件第 2、3 节；
3. 双方确认「新增字段是可选还是必填」，可选字段必须给默认值；
4. 页面层不允许出现兼容分支（`if (x.newField !== undefined)`），默认值在 API 层补齐。
